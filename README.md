# テトリス for iPad 🎮

iPad（およびスマホ・PC）のブラウザで遊べるテトリスです。タッチ操作に最適化されており、Vercel で簡単に公開できます。

## 特徴

- 📱 **iPad / タッチ操作対応** — 画面下のボタンに加え、盤面上のスワイプ操作にも対応
- 👻 ゴーストピース表示（落下位置のプレビュー）
- 🔄 HOLD / NEXT（3つ先まで表示）
- 🎒 7-bag 方式のランダム生成
- ⚡ レベルに応じた落下速度アップ・スコア計算
- 🖥 キーボード操作（PCでのテスト用）

## 操作方法

### タッチ（iPad）
| 操作 | 動作 |
| --- | --- |
| 盤面を左右にドラッグ | 左右移動 |
| 盤面を下にドラッグ | ソフトドロップ |
| 盤面をタップ | 回転 |
| 下に素早くフリック | ハードドロップ |
| 上にスワイプ | ホールド |
| 画面下のボタン | 各操作（◀ ⟳ ▶ HOLD ▼ DROP） |

### キーボード（PC）
- ← → : 移動
- ↑ / X : 回転
- ↓ : ソフトドロップ
- スペース : ハードドロップ
- Shift / C : ホールド
- P : 一時停止

## ローカルで動かす

ビルド不要の静的サイトです。任意の静的サーバーで開けます。

```bash
npm run dev      # npx serve でローカル配信
# もしくは
python3 -m http.server 8000
```

ブラウザで `http://localhost:3000`（または `:8000`）を開きます。

## Vercel へのデプロイ

ビルド設定は不要です（Framework Preset は **Other** / 静的サイト）。

### 方法 A: ダッシュボードから
1. このリポジトリを GitHub に push
2. [vercel.com](https://vercel.com) でリポジトリを **Import**
3. 設定はそのまま **Deploy** を押すだけ

### 方法 B: CLI から
```bash
npm i -g vercel
vercel          # プレビューデプロイ
vercel --prod   # 本番デプロイ
```

デプロイ後に発行される URL を iPad の Safari で開けば、そのまま遊べます。Safari の「ホーム画面に追加」をすると全画面アプリのように起動できます。
